# Chivo Radar - Event Scraper  
This repository implements a web scraper that checks many of the top Costa Rican ticketing websites for new and upcoming concerts and events, taking their basic information (such as their ticket tiers, location via a geocoding API, time of opening) and executes an upsert operation in MongoDB.
